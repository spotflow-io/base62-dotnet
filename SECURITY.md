# Security Policy

## Reporting a Vulnerability

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/spotflow-io/base62-dotnet/security/advisories/new). Do not disclose a vulnerability in a public issue before a fix is available.

Reports may alternatively be sent to `security@spotflow.io`. Please include enough information to reproduce and assess the issue. We will acknowledge the report, investigate it, and coordinate disclosure after a fix is available.

This project does not currently operate a bug bounty program.
